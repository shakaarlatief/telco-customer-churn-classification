\begin{abstract}
This report presents a machine learning project on customer churn prediction using the Telco Customer Churn dataset. The task is formulated as a binary classification problem, where the objective is to predict whether a customer will churn based on customer, contract, service, and billing characteristics.

The report follows a structured modelling workflow. It begins with data understanding, data-quality inspection, feature exploration, cleaning decisions, and train-test split construction. Later sections build on this foundation by introducing classification models, comparing their predictive performance, and interpreting the results. The aim is to produce a clear, reproducible, and professionally documented machine learning analysis.
\end{abstract}
