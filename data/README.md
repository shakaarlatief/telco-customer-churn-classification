# Data

This folder contains local data files for the Telco Customer Churn project.

The raw dataset is not committed to Git, because datasets from external sources should usually be downloaded separately and stored locally.

## Dataset

Dataset: Telco Customer Churn  
Source: Kaggle  
URL: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

After downloading and extracting the dataset, place the CSV file in:

```text
data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv
